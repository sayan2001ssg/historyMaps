CBSE History Map Work - Class XII
=================================

How to use (no internet needed)
1. Unzip this folder anywhere (computer, pen drive, or phone storage).
2. Double-click index.html. It opens in any modern browser (Chrome, Edge, Firefox, Safari).
3. Choose a map from the list, study it, then press "Start test".

Notes
- Everything (map, places, questions) is inside index.html. No internet connection is used.
- Best scores are saved in the browser on that device.
- Locate questions: a mark within 60 km is full marks, within 120 km is half marks.
  For areas (Mahajanapadas, kingdoms, provinces) any tap inside the shaded zone counts.
- Map data: Natural Earth (public domain), India's official boundaries.
